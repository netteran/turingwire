OpenAI has launched a Computer History feature that enables users to create a searchable memory timeline from their interactions with ChatGPT and Codex. This data is stored locally as unencrypted Markdown files, allowing for easy access and organization. While OpenAI asserts that the memories are not used for AI training, it acknowledges that memories feeding into chats may still end up as training data. This feature enhances user experience by allowing more personalized interactions based on past inputs, a notable shift in how users can leverage their historical data in AI conversations. For developers, this means improved context retention in applications built on ChatGPT and Codex.
