Claude Code has created 388 pull requests for Anthropic's software, achieving a 46 percent merge rate after human review. Boris Cherny, the inventor of Claude Code, noted that there are "early signs of life that this might be possible" for automated maintenance capabilities. Testing of these capabilities is expected to occur in a few weeks. This development follows Anthropic's recent initiatives to enhance Claude's functionality, including setting Claude Code to auto mode by default for Pro Plans, which may streamline future maintenance processes. According to [The Decoder](https://the-decoder.com/claude-code-now-runs-daily-maintenance-on-anthropics-software-with-a-46-percent-merge-rate/), this marks a significant step in integrating AI-driven tools into software maintenance workflows.
