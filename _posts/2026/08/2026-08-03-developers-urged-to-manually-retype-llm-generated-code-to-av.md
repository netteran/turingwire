In 2026, developers are advised to manually retype code generated by Large Language Models (LLMs) to mitigate cognitive debt. An anonymous developer stated, "I want to understand every line of code that goes into this project," emphasizing the importance of comprehension over mere productivity. This method is reported to make manual coding with LLMs 2x faster than relying solely on LLM outputs. The developer expressed concern that the software industry is accumulating cognitive debt that will need to be addressed, asserting, "Anything else would be professional malpractice." This advice echoes past recommendations from developers during their teenage years, advocating for manual coding as a learning tool. The shift towards LLM-generated code in the coming months necessitates a balance between efficiency and understanding, as highlighted in discussions on [Hacker News (AI filtered)](https://ankursethi.com/blog/prevent-cognitive-debt-by-manually-retyping-llm-generated-code/).
